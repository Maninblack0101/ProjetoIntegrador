
NEXUS GAMES — COMO EXECUTAR

1. Crie uma pasta chamada nexus-games.
2. Salve os arquivos index.html, style.css e script.js
   dentro dessa pasta.
3. Salve este guia como README.txt.
4. Abra o arquivo index.html no navegador.

FUNCIONALIDADES
- Catálogo de jogos.
- Pesquisa por nome.
- Filtro por categoria.
- Carrinho com total e remoção de itens.

IMPORTANTE
Este projeto é uma demonstração.
Não possui pagamento integrado, banco de dados,
estoque ou entrega automática de jogos digitais.

Para vender de verdade, será necessário integrar
um provedor de pagamentos e configurar a entrega
dos produtos adquiridos.
